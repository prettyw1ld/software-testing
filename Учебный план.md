## Результаты ресерча актуальности

Дата ресерча: 2026-10-04. Уровень надёжности: A — первоисточник или официальная документация, B — профильный блог или опрос с методикой, C — агрегатор или SEO-блог, цифры расходятся.

| Область | Что актуально сейчас | Вывод для курса | Надёжность |
|---|---|---|---|

В State of JS 2025 отмечен рост node:test, удовлетворённость Jest ниже, чем у Vitest | Основной инструмент курса Jest. ## Решения

| ID | Решение | Обоснование |
|---|---|---|
| D1 | Jest — основной инструмент unit-тестов. Vitest упоминается как альтернатива с почти идентичным API | ПР 5 и 6 уже написаны на Jest и проверены |
| D2 | Весь код в примерах переводится с C# на JavaScript и Node.js | Профиль курса — веб-разработка |
| D3 | Клиент для API: Bruno по умолчанию, Postman допустим | Bruno работает без аккаунта и хранит коллекции в git |
| D4 | Нагрузочное тестирование: k6 вместо JMeter, JMeter как сравнительный пример | Скрипты на JS, единый стек |
| D5 | Кроссплатформенное тестирование (ПР 18) выполняется в современных браузерах, Internet Explorer исключается | Internet Explorer снят с поддержки в 2022 году |
| D6 | Анализ кода (ПР 14) на ESLint и SonarQube Community вместо Platform V Works::CodeScanner | CodeScanner недоступен студентам |
| D7 | Добавляются работы 21-26 | Закрывают пробелы по запросу рынка |
| D8 | Сквозной веб-проект: студент берёт один проект и ведёт его через все работы | Снимает разнобой «по варианту / своё ПО / курсовой» |
| D9 | СУБД в ПР 12 (и других работах с БД): MySQL. Клиент по выбору студента: MySQL Workbench или phpMyAdmin. SQL Server не используется | Решение по запросу автора выбрать между сохранением SQL Server и MySQL с Workbench или phpMyAdmin. Выбран MySQL, так как с SQL Server пришлось бы тащить стек .NET |
| D10 | Привязка вариантов к студентам: номер варианта = ((номер в журнале − 1) mod N) + 1, где N — число вариантов в работе. Для ПР 5 N = 10 | Автор передал выбор. Простое правило без ручного распределения. Если в работе требуется уникальность решений у каждого студента, одного номера варианта недостаточно, добавь выбор предметной области или проекта |
