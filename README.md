# Практические работы по тестированию информационных систем

Комплект методичек по дисциплине «Тестирование информационных систем» для специальности 09.02.09 Веб-разработка (разработчик веб-приложений). Состав и порядок работ описаны в файле [Учебный план.md](Учебный%20план.md).

## Важное

- Практические работы №1 и №2 в комплект не входят. Студенты, выполнившие их по прежним методичкам, по новым методичкам их не выполняют.
- Практические работы №5 и №6 рекомендуется выполнять после ПР 14 МДК.03.03.
- Номер варианта, если в работе не сказано иное: ((номер в журнале − 1) mod N) + 1, где N — число вариантов в работе. Пример: при 10 вариантах студент с номером 12 в журнале выполняет вариант 2.
- Остальные работы комплекта добавляются в репозиторий по мере готовности.
